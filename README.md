# 🌍 Country Explorer (REST API Integration)

A dynamic and interactive web application that allows users to explore comprehensive global data by fetching real-time information from a country REST API. This project was built as a hands-on practice milestone for front-end web development with the **IBM SkillsBuild** curriculum.

---

## 🚀 Live Features

- **🌐 Live REST API Integration:** Fetches accurate, real-time global data directly from an external country API endpoint.
- **🔍 Smart Search by Name:** Find any country instantly by typing its name in the search bar.
- **📊 Filter by Population:** Sort and browse through countries based on their demographic sizes.
- **🗺️ Filter by Region:** Seamlessly narrow down your search by continents or regions (e.g., Africa, Americas, Asia, Europe, Oceania).
- **📋 Detailed Info Page:** Click on any country card to navigate to a dedicated layout showcasing currency, capital, languages, borders, and flag details.

---

## 🛠️ Tech Stack & Skills Practiced

- **Languages:** HTML5, CSS3, JavaScript (ES6+)
- **API Handling:** Fetch API, Async/Await, handling JSON responses, and dynamic DOM manipulation.
- **UI/UX Design:** CSS Grid/Flexbox for a responsive card catalog layout, mobile-first design, and interactive interface states.

## 🔍 About the Project

This application serves as a practical exploration of front-end engineering concepts. By replacing static local mock data with a live **REST API**, it simulates a real-world web environment dealing with asynchronous data fetching, error loading states, and complex array filtering methods (such as `.filter()` and `.slice()`).

---

## ⚙️ How to Run Locally

Want to test this project or view the code working on your local machine? Follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project folder:**
   ```bash
   cd Country_Explorer_using_rest_api
   ```

3. **Launch the application:**
   - Simply double-click the `index.html` file to run it in your browser.
   - *Alternative:* If using VS Code, right-click `index.html` and select **Open with Live Server**.
